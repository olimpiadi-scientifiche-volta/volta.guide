## Variabili
Possiamo immaginare una variabile come una scatola con un'etichetta: il nome è scritto sull'etichetta e dentro la scatola c'è il valore. In C++, a differenza di altri linguaggi come Python, ogni variabile ha anche un tipo immutabile che rappresenta il tipo di oggetti che la scatola può contenere. In generale la sintassi è: ```tipo NOME = VALORE;```.

### Booleani
Si indicano con la keyword ```bool``` e possono assumere solo due valori: ```true``` o ```false```. Ad esempio: 
```cpp 
bool flag = true;
```

### Interi
Si indicano con la keyword ```int``` e si usano per rappresentare dei numeri compresi tra $-2^{31}$ e $2^{31} - 1$. Se usate la keyword ```long long``` potete rappresentare numeri compresi tra $-2^{63}$ e $2^{63} - 1$. Ad esempio:
```cpp
int martino = 42;
long long casadei = 676767677;
```

<details>
<summary>Perché proprio questi numeri?</summary>

Un numero non è altro che una [sequenza binaria](https://it.wikipedia.org/wiki/Sistema_numerico_binario) e ogni cifra è un bit (binary digit) e un gruppo di 8 bit si chiama byte. Un ```long long``` occupa 8 byte e in 64 bit possiamo rappresentare numeri fino a $2^{63}$, mentre un ```int``` occupa solo 4 byte e ha 32 bit per rappresentare numeri fino a $2^{31}$. Un bit viene usato per indicare il segno e aggiungendo la keyword ```unsigned``` possiamo rappresentare il doppio dei numeri.  
</details>

#### Operazioni
[Qui](https://en.cppreference.com/cpp/language/operator_precedence) trovate la priorità di ogni operazione, per modificare l'ordine di un'espressione potete usare le parentesi tonde. Le principali operazioni sono:
- ```a + b```, eventualmente potete usare anche ```a++``` che aggiunge 1
- ```a - b```, eventualmente potete usare anche ```a--``` che sottrae 1
- ```a * b``` per moltiplicare due interi
- ```a / b```, nota che la divisione tra interi sarà un numero intero (i.e. il risultato viene arrotondato per difetto)
- ```a % b``` per trovare il resto della divisione (intera) tra due interi

**Attenzione**: scrivere solo ```a + b``` non modifica il valore di nessuna variabile, per assegnare a una variabile il risultato di un'espressione dobbiamo scrivere ad esempio ```a = a + b```.

### Vettori
Un vettore è una lista di elementi **dinamica** (i.e. la sua grandezza può cambiare), tutti dello stesso tipo. Si usa la keyword ```vector``` e si indica il tipo degli elementi tra parentesi angolari. Tra parentesi tonde possiamo indicare il numero di elementi e il loro valore iniziale. Per accedere a un elemento in una determinata posizione possiamo indicare l'indice tra parentesi quadre. Ad esempio:
```cpp
vector<bool> michele;
vector<int> trapani(6, 7); // trapani = {7, 7, 7, 7, 7, 7} 
trapani[4] = 2;
```

#### Metodi
I metodi sono funzioni dichiarate direttamente all'interno di una struttura dati. Per accedere a un metodo si usa il nome della struttura dati seguito da un punto e dal nome della funzione. I principali sono:
- ```empty()``` ritorna _true_ se il vettore è vuoto, _false_ altrimenti
- ```size()``` ritorna il numero di elementi contenuti nel vettore
- ```clear()``` "svuota" il vettore
- ```push_back(x)``` aggiunge l'elemento _x_ in fondo al vettore
- ```pop_back()``` rimuove l'ultimo elemento

#### Sort
Per _sortare_ (i.e. ordinare) un intervallo di elementi, potete usare la funzione ```sort(first, last, comp)```. ```first``` e ```last``` sono [iteratori](https://www.w3schools.com/cpp/cpp_iterators.asp), e definiscono il range [first, last) di elementi da ordinare. ```comp``` è un parametro opzionale ed è la funzione usata per confrontare due elementi. Il modo migliore è usare una [lambda](). 
```cpp
sort(begin(trapani), end(trapani));
```

## Trova la somma pari massima
<LinkCard title="easy2" href="https://training.olinfo.it/task/easy2" />

<details>
<summary>Soluzione</summary>

[...]

```cpp
#include <bits/stdc++.h>

using namespace std;

int main() {
	int N;
	cin >> N;

	vector<int> A(N), B(N);
	
	for (int i = 0; i < N; i++) {
		cin >> A[i] >> B[i];
	}

	int ans = -1;

	for (int i = 0; i < N; i++) {
		if ((A[i] + B[i]) % 2 == 0) {
			ans = max(ans, A[i] + B[i]);
		}
	}

	cout << ans << '\n';
}
```
